# Studio concept

Open `index.html` directly in a browser. No Laravel, npm install, build, server or external asset requests are required.

Optional local preview, from this directory:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then visit http://127.0.0.1:4173.

- `index.html`: Turkish content, inline SVG artwork and semantic page sections.
- `styles.css`: palette, three responsive typography roles and mobile layouts.
- `script.js`: progressively enhanced mobile menu. Navigation stays visible without JavaScript.
- `assets/`: local Geist Latin/Latin Extended font subsets copied from the existing project, font license and favicon.

T-MAX DevLab is a provisional name. Change the two `[data-brand-name]` wordmarks, their accessible labels and the document title before choosing a permanent identity. There is no domain, hosting setup, permanent logo or business registration implied by this concept. The prototype is marked `noindex, nofollow`.

Project cards describe Timurhan Kaya's existing freelance, employment and cofounder work. They do not claim those projects as studio customers. The typographic covers are illustrative artwork for this concept, not official client logos. Some source projects are intentionally hidden on the personal public site; this local concept does not change their publication status.

Contact links open the existing email address in the visitor's mail application. There is no form, submission endpoint, analytics or tracking. The personal site's code, content and URLs remain unchanged.
